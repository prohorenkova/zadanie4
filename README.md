****Развертывание статического сайта через Docker****

Проект предназначен для запуска статического сайта (HTML, CSS, JS) в контейнере Nginx с помощью Docker. Изменения в файлах сайта сразу отображаются в браузере без перезапуска контейнера.

****Структура проекта****

```
nginx-static/
├── docker-compose.yml   # описание контейнера
├── nginx.conf           # конфигурация nginx
└── site/                # файлы сайта (монтируются в контейнер)
    └── index.html
```

****Ход выполнения****

- Установлен Docker Desktop

- Запущен контейнер командой: docker compose up -d

- Работа сайта проверена по адресу http://localhost:8080.

- Статус контейнера проверен командой docker compose ps.

****Команды управления****

- docker compose ps — отображает статус контейнера.

- docker compose logs -f — выводит логи Nginx в реальном времени.

- docker compose restart — перезапускает контейнер (после правки nginx.conf).

- docker compose down — останавливает и удаляет контейнер.
